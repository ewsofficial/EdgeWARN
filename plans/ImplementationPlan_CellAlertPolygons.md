# Implementation Plan: Cell Alert Polygon Templates (Projection Buffer Method)

## Goal Description
Integrate cell alert polygon templates into the EdgeWARN-Core real-time processing pipeline. The alert polygon will be generated by projecting the actual storm footprint forward in time (30 min) along the StormCast forecast track, expanding the shape to account for increasing uncertainty, and creating a final buffered polygon representing the threatened area. This will be integrated as a CTAM core process.

## Proposed Changes

### CTAM Architecture
#### [MODIFY] `src/EdgeWARN/core/ctam/run.py`
- Ensure a "pre-module" step generates the base footprint polygon for every cell.
- This satisfies the requirement: "Generate a polygon for each cell before continuing with modules".

#### [NEW] `src/EdgeWARN/core/ctam/modules/Footprint.py`
- Implement a `FootprintModule` (AnalysisModule) that runs first.
- Logic: Takes the cell's `bbox` and generates a standard `shapely.geometry.Polygon` stored in `storm_entry['polygon']`.

#### [NEW] `src/EdgeWARN/core/ctam/modules/CellAlert.py`
- Implement a `CellAlertModule` (AnalysisModule) that runs after `StormCast`.
- **Logic (The Projection Buffer Method)**:
  1. **Projection**: Retrieve the base footprint polygon and the StormCast `forecast_cones` (up to `ALERT_LEAD_TIME_SECONDS`, e.g., 30m).
  2. **Advection & Expansion**: For each forecast time step:
     - Translate the footprint polygon along the displacement vector to the forecast center.
     - Buffer/Expand the translated polygon by the dynamic uncertainty radius at that lead time.
  3. **Final Shape**: Compute the `convex_hull` or `union` of the original footprint and all projected/expanded polygons.
  4. **Frequency & Smoothing**:
     - To prevent the alert polygon from shifting wildly between scans, only generate a fresh `alert_polygon` every 3 scans (or if no previous polygon exists).
     - In intervening scans, retrieve the previous `alert_polygon` from `cell['history']` and advect it based on the current storm velocity, or simply retain it if displacement is small.
  5. **Persistence**: Save the resulting polygon as `storm_entry['modules']['CellAlert']['alert_polygon']`.

#### [MODIFY] `src/EdgeWARN/core/ctam/modules/__init__.py`
- Register `FootprintModule` first.
- Register `CellAlertModule` after `StormCastModule`.

### Configuration
#### [MODIFY] `src/EdgeWARN/core/process/integrate/config.py`
- Add `ALERT_LEAD_TIME_SECONDS` (default 1800s).
- Add `ALERT_SAFETY_BUFFER_DEGREES` (e.g., 0.05).
