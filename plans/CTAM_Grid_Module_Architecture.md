# CTAM Grid Module Architecture Plan

## Background

The current CTAM (Common Temporal Analysis Module) architecture is designed exclusively for per-cell processing. Each module receives storm cell data and modifies it in-place. However, some analysis modules — like flash flood detection — operate on grid-based raster data (GRIB/NetCDF files) and produce GeoJSON features rather than per-cell results.

This plan adds support for grid-based CTAM modules while maintaining the existing cell-based module architecture.

---

## Current Architecture

The current CTAM has:
- `AnalysisModule` base class with `run(cell)` method
- Single `ModuleRegistry` for all modules
- Runner that iterates over cells and applies modules to each cell

---

## Proposed Changes

### 1. Two Separate Registry Classes

#### [MODIFY] registry.py (src/EdgeWARN/core/ctam/registry.py)

```python
class CellModuleRegistry:
    """
    Registry for cell-based CTAM modules.
    These modules operate on storm cell data and modify cells in-place.
    """
    _modules: Dict[str, AnalysisModule] = {}
    
    @classmethod
    def register(cls, module: AnalysisModule):
        cls._modules[module.name] = module
    
    @classmethod
    def get_all(cls) -> Dict[str, AnalysisModule]:
        return cls._modules.copy()


class GridModuleRegistry:
    """
    Registry for grid-based CTAM modules.
    These modules operate on raw data files (GRIB/NetCDF) and produce
    GeoJSON features rather than per-cell results.
    """
    _modules: Dict[str, 'GridAnalysisModule'] = {}
    
    @classmethod
    def register(cls, module: 'GridAnalysisModule'):
        cls._modules[module.name] = module
    
    @classmethod
    def get_all(cls) -> Dict[str, 'GridAnalysisModule']:
        return cls._modules.copy()
```

### 2. Add GridAnalysisModule Base Class

#### [MODIFY] interface.py (src/EdgeWARN/core/ctam/interface.py)

Add new base class:

```python
class GridAnalysisModule(ABC):
    """
    Grid-based module - operates on raw data files (GRIB/NetCDF).
    Does not require storm cells; runs independently on raster data.
    """
    
    @property
    @abstractmethod
    def name(self) -> str:
        """The unique name of the module."""
        pass
    
    @abstractmethod
    def run(self) -> Dict[str, Any]:
        """
        Run grid-based analysis on raw data files.
        
        Returns:
            Dict with:
                - 'features': GeoJSON FeatureCollection of detected regions
                - 'metadata': Processing metadata
                - 'timestamp': Analysis timestamp
        """
        pass
    
    def alerts(self, features: List[Dict[str, Any]]) -> Optional[List[AlertPayload]]:
        """
        Return alert payloads generated by this module,
        or None if no alerts are produced.
        """
        return None
```

### 3. Update CTAM Runner

#### [MODIFY] run.py (src/EdgeWARN/core/ctam/run.py)

```python
def run_ctam(cells: List[Dict[str, Any]]) -> List[Dict[str, Any]]:
    """
    Run all registered CTAM modules on the provided storm cells.
    
    First runs cell-based modules, then runs grid-based modules.
    Grid results are attached to the first cell for output.
    """
    start_time = time.time()
    
    print("[CTAM] Starting CTAM pipeline...")
    
    # Get registered modules
    cell_modules = CellModuleRegistry.get_all()
    grid_modules = GridModuleRegistry.get_all()
    
    print(f"[CTAM] Cell modules: {list(cell_modules.keys())}")
    print(f"[CTAM] Grid modules: {list(grid_modules.keys())}")
    
    # Step 1: Run cell-based modules
    for cell in cells:
        for module in cell_modules.values():
            try:
                module.run(cell)
            except Exception as e:
                cell["modules"][module.name] = {"status": "error", "error": str(e)}
    
    # Step 2: Run grid-based modules
    grid_results = {}
    for module in grid_modules.values():
        try:
            result = module.run()
            grid_results[module.name] = result
            
            # Generate alerts from grid results
            if result.get("features"):
                alerts = module.alerts(result["features"])
                if alerts:
                    AlertManager.publish_many(alerts)
                    
        except Exception as e:
            grid_results[module.name] = {"status": "error", "error": str(e)}
    
    # Attach grid results to first cell (or create placeholder)
    if cells:
        cells[0]["modules"]["_grid_outputs"] = grid_results
    else:
        # No cells, but grid modules ran - store results separately
        cells = [{"modules": {"_grid_outputs": grid_results}}]
    
    total_elapsed = time.time() - start_time
    print(f"[CTAM] Pipeline complete in {total_elapsed:.3f}s")
    
    return cells
```

    def run(self) -> Dict[str, Any]:
        """
        Run flash flood detection on FLASH GRIB files.
        
        Returns:
            Dict with:
                - 'features': GeoJSON FeatureCollection
                - 'metadata': Processing metadata
                - 'timestamp': Analysis timestamp
        """

        # Load FLASH GRIB files
        grids = self._load_grids()
        if grids is None:
            return {
                "features": {"type": "FeatureCollection", "features": []},
                "metadata": {"error": "Failed to load grids"},
                "timestamp": datetime.now().isoformat()
            }
        
        # Compute threat scores
        threat_grid, rainfall_grid, hydro_grid, ffg_grid, rqi_grid = compute_threat_grid(
            grids["ari_max"],
            grids["ari_30m"],
            grids["ari_01h"],
            grids["crest_streamflow"],
            grids["hp_streamflow"],
            grids["soil_sat"],
            grids["ffg_ratio"],
            grids["rqi"],
        )

            "rainfall": rainfall_grid,
            "hydro": hydro_grid,
            "ffg": ffg_grid,

            threat_grid,
            grids["latitude"],
            grids["longitude"],

            config["MIN_REGION_AREA_KM2"],

## Backward Compatibility

The existing `ModuleRegistry` class should be aliased to `CellModuleRegistry` for backward compatibility:

```python
# Alias for backward compatibility
ModuleRegistry = CellModuleRegistry
```

Existing cell-based modules will continue to work without modification.
